# Calculadora gRPC

Projeto de calculadora distribuída que utiliza gRPC para a comunicação entre cliente e servidor.

# Vídeo Explicativo:
[Clique aqui para visualizar o vídeo](https://drive.google.com/drive/folders/17UxjJ6sdeooVr94Hui_chL9w_LO_De2T?usp=sharing)

## Sobre o projeto

O servidor recebe solicitações de cálculo por meio de uma API gRPC, processa as operações e devolve os resultados ao cliente.

**Operações disponíveis:** 
- soma
- subtração
- multiplicação
- divisão
